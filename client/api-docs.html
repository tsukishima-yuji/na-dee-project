Na-Dee API

Cassava yield scenarios from the DSSAT crop model (32 scenarios: 4 varieties × 2 planting dates × 2 water × 2 nitrogen), plus a live planting-readiness check built on the Open-Meteo weather API. The Na-Dee web app uses these same URLs. No key needed; read endpoints allow cross-origin calls.

Base URL https://statuesque-pavlova-991b3b.netlify.app
POST/api/matchPredict yield for one field GET/api/planting-checkIs now a good time to plant? (calls Open-Meteo) GET/api/scenariosAll 32 yield scenarios

POST/api/match

Send the 4 field conditions and the field size. Returns the matching scenario with the whole-field yield (normal-year range) and the 3 alternatives for the same variety and planting date.

Request body (JSON)

FieldTypeAllowed values
varietystringKU50 Kasetsart 50 · RY9 Rayong 9 · RY11 Rayong 11 · CMR38 CMR38-125-77
planting_datestringearly early rainy season (May) · late late rainy season (Oct)
irrigation_typestringrain_fed · system (full irrigation)
nitrogenstringapplied (90 kg N/ha) · not_applied
cultivated_areanumberfield size in rai, > 0

Example request

curl -X POST https://statuesque-pavlova-991b3b.netlify.app/api/match \
  -H "Content-Type: application/json" \
  -d '{"variety":"RY11","planting_date":"late",
       "irrigation_type":"rain_fed","nitrogen":"applied",
       "cultivated_area":8}'
// JavaScript
const res = await fetch("/api/match", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ variety: "RY11", planting_date: "late",
    irrigation_type: "rain_fed", nitrogen: "applied", cultivated_area: 8 }),
});
const { best, alternatives } = await res.json();

Errors

400a field is missing or not an allowed value, e.g. {"error":"variety must be one of KU50, RY9, RY11, CMR38"}
404no scenario for this combination

    


    
    

      
GET/api/planting-check

      
Turns live weather into a planting decision. Our server calls the external
        Open-Meteo Forecast API (https://api.open-meteo.com/v1/forecast) with
        daily=precipitation_sum, hourly=soil_moisture_3_to_9cm, past_days=7, forecast_days=14,
        then returns soil moisture, past and expected rain, and a verdict. Cached 30 minutes.

      
Query parameters (optional)

      

        
NameTypeDefault

        
latnumber, -90..9016.47 (Khon Kaen University farm)

        
lonnumber, -180..180102.81

      

      

        
Example request


curl "https://statuesque-pavlova-991b3b.netlify.app/api/planting-check"
curl "https://statuesque-pavlova-991b3b.netlify.app/api/planting-check?lat=15.0&lon=102.1"

          
Verdict rules

          

            
goodsoil not dry (≥ 0.12 m³/m³) and ≥ 30 mm rain expected in 14 days

            
irrigatesoil not moist (< 0.20) and < 30 mm rain expected

            
watchanything in between

          

        
Sample response


{
  "location": { "lat": 16.47, "lon": 102.81,
                "name": "Khon Kaen (KKU farm)" },
  "soil_moisture_now": 0.143,     // m³/m³
  "soil_status": "fair",          // moist | fair | dry
  "rain_past_7d_mm": 13.2,
  "rain_next_14d_mm": 9.8,
  "daily": [ { "date": "2026-10-26", "rain_mm": 3.2,
               "forecast": false }, ... ],
  "verdict": "irrigate",          // good | watch | irrigate
  "source": "Open-Meteo Forecast API (api.open-meteo.com)",
  "fetched_at": "2026-11-01T15:40:12.000Z"
}

      

      
502 is returned if Open-Meteo cannot be reached; the app then hides the card and keeps working.

      

      

    


    
    

      
GET/api/scenarios

      
All yield scenarios (32 research scenarios from DSSAT, ids 1001–1032, plus any added by the admin).
        Each one has Thai and English text.

      

        
Example request


curl https://statuesque-pavlova-991b3b.netlify.app/api/scenarios

          
Main fields

          

            
predicted_yieldfresh root yield, t/rai (29-season mean)

            
yield_sdyear-to-year variation, t/rai

            
yield_dry_kg_haDSSAT dry root weight, kg/ha

            
dmc_pctdry matter % used to convert dry → fresh

          

          
Admin endpoints (used by the dashboard): POST /api/scenarios, PUT /api/scenarios/:id,
            DELETE /api/scenarios/:id, POST /api/scenarios?reset=1.
